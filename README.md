# Порезки металла

Статическое веб-приложение без сервера: достаточно открыть `index.html` в браузере или разместить содержимое этой папки на GitHub Pages / Cloudflare Pages.

## Что считает текущая версия

- номенклатуру: лента, лист или карточка;
- номенклатуру «Рулон / перемотка» без продольного раскроя;
- для любой карточки проверку обоих направлений: ширина×длина и длина×ширина;
- смешанные схемы полос в одном рулоне, например 1×400 + 2×500 мм;
- ввод количества в тоннах или метрах для ленты/рулона и в тоннах или штуках для листа/карточки;
- перевод выбранного количества в тонны для единого результата в руб/т с НДС;
- плёнку с одной или двух сторон; двухсторонняя плёнка доступна до толщины 2,0 мм;
- при двухсторонней плёнке добавляется вторая перемотка на шлифовке и двойная стоимость плёнки;
- три автоматически подобранные ширины рулона для ленты/карточки;
- автоматический выбор тарифа полного, частичного или открытого рулона;
- ограничения по количеству полос и минимальному откройнику 7 мм;
- ручную ширину рулона;
- металл отдельно от переработки;
- отдельный ввод прайса готового изделия;
- расчёт стоимости откройника от себестоимости материала;
- переработку одной строкой и расшифровкой: порезка + плёнка + шлифовка;
- последовательность операций: для шлифованной продукции сначала шлифовка, затем резка; для карточки — шлифовка (если выбрана), продольная резка в ленту, затем поперечная резка;
- для второй операции автоматически применяется открытый рулон до конца;
- шлифовку рулона по толщине и шлифовку листа по отдельному тарифу;
- минимальные объёмы прайсов: 3 т для продольной резки и шлифовки рулона, 2 т для поперечной резки, 1 т для шлифовки листа;
- доплаты за особые условия, поддон и скидку за дальнейшую переработку;
- лист без расчёта откройника — один вариант по ширине листа.

Текущие условия прайса находятся в объекте `PRICE` файла `app.js`. Цены включают НДС и основаны на присланных прайсах CAMU, LDM/ERIS и ROTOR от 01.03.2026. Все значения сохраняются только в браузере пользователя.

## Бесплатная публикация

### GitHub Pages

1. Создайте новый публичный репозиторий на GitHub.
2. Загрузите в него `index.html`, `styles.css`, `app.js` и `README.md`.
3. Откройте **Settings → Pages**, выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`.
4. Через несколько минут GitHub покажет публичный адрес вида `https://имя.github.io/имя-репозитория/`.

### Cloudflare Pages

1. Создайте проект в Cloudflare Pages и подключите GitHub-репозиторий.
2. Для статического проекта оставьте команду сборки пустой.
3. В качестве папки вывода укажите `/` (корень проекта) и нажмите Deploy.

После публикации ссылку можно открывать на телефоне, планшете и компьютере в любом современном браузере.

## Закрытый доступ без загрузки в интернет

Если коммерческую программу нельзя размещать в интернете, используйте `start-private.ps1` на рабочем компьютере. Скрипт запускает локальный веб-сервер, а файлы остаются только на этом компьютере.

1. Запустите `start-private.ps1`.
2. На этом компьютере откройте `http://localhost:8000/`.
3. На другом устройстве в той же Wi-Fi сети откройте `http://IP-КОМПЬЮТЕРА:8000/`.

IP компьютера можно посмотреть командой `ipconfig` в Windows. Для доступа из другой сети нужен закрытый VPN до офиса или домашней сети; без сервера или VPN ссылку «из любого места» сделать невозможно, потому что приложение должно где-то выполняться.

Другой вариант — держать программу на рабочем компьютере и подключаться к нему через Tailscale/ZeroTier. В этом случае файлы не публикуются, а доступ получают только авторизованные устройства в закрытой виртуальной сети. У бесплатного Personal-плана Tailscale есть ограничение на некоммерческое использование, поэтому для коммерческой работы нужно проверить условия тарифа; ZeroTier также имеет бесплатный базовый вариант для небольших сетей.

## Единицы расчёта для ленты

Масса заказа указывается для **готовой ленты**. Масса исходного рулона определяется через выход годного металла. Все затраты на переработку исходного металла (включая минимальную партию по прайсу) приводятся к **руб/т готовой ленты**, прежде чем сравнивать варианты раскроя. При равной итоговой цене выбирается вариант с большим выходом годного металла.

## Смешанный раскрой через подкаты (версия 2026.11.23.2)

Для заказа ленты нескольких ширин рассчитываются прямые и двухэтапные схемы.
Двухэтапная схема: исходный рулон → 2–4 промежуточных рулона → готовые
ленты. Каждый подкат может содержать несколько типоразмеров. На каждом
проходе независимо проверяется максимальное количество лент, а откройник
учитывается и у исходного рулона, и у каждого подката. Поиск в сложных
случаях использует ограничение числа вариантов, поэтому **лучший найденный**
не означает доказанный глобальный оптимум.

Первый проход оценивается по массе исходного рулона. Второй проход оценивается
по фактической массе проходящих через станок подкатов с учётом тарифов,
зависящих от их ширины. Финальная цена выражена в руб/т готовых лент.

Параметр **«Откройник меньше разрешённого»** снижает минимальный откройник
с 7 до 6 мм (никогда ниже 6 мм), выключен по умолчанию и применим только
для ленты. Использовать после согласования с производством. Отдельная
доплата за уменьшенный откройник автоматически не добавляется.

## Гибридный двухэтапный раскрой ленты (2026.11.24.1)

Для смешанного заказа дополнительно ищется схема **один проход исходного рулона →
часть готовых лент плюс один подкат → повторная резка только подката**.
Первый проход ограничен числом одновременно получаемых полос/подкатов,
второй — лимитом для ширины конкретного подката. Везде сохраняется
минимальный откройник 7 мм или 6 мм при включении отдельного флажка.

При формировании цены первый проход относится к массе исходного рулона,
второй — лишь к массе подката. Это две операции продольной резки;
одна операция не начисляется отдельно на каждую готовую полосу.
Программа продолжает сравнивать варианты с прямой резкой и несколькими подкатами.

Для нескольких типоразмеров установлен настраиваемый допуск по массе
каждой ширины (по умолчанию ±10%). Из вариантов, соответствующих допуску,
выбирается **минимальная итоговая стоимость** с учётом всех операций и
откройника. Если подходящих схем не найдено, выводится ближайшая по массе
с предупреждением. Поиск сложных заявок ограничен по числу кандидатов,
поэтому глобальный оптимум не гарантируется.

## Выбор исходной ширины и комбинированные подкаты (v2026.11.24.3)

Второй шаг формы ленты содержит селектор «Ширина исходного рулона»:
**Любая (автоподбор)** / **1000** / **1219** / **1250** / **1500 мм**.
Конкретная ширина ограничивает весь автоматический поиск; «Любая»
сравнивает все стандартные ширины. Выбор сохраняется между расчётами.
Для листов, карточек и перемотки это поле скрыто и прежняя логика
не меняется.

Добавлен расчёт комбинированного первого прохода:
**готовые ленты + 2 или 3 подката**, с последующей резкой только подкатов.
Таким образом доступны прямая резка, готовые ленты + 1/2/3 подката и
маршруты только через подкаты. Резка исходного рулона оплачивается
**один раз**, а повторная — по суммарной массе фактически нарезаемых
подкатов, с учётом тарифов каждого подката. Ножевые лимиты и минимальный
откройник (7 мм или явно разрешённые 6 мм) проверяются на каждом проходе.

На третьем шаге показываются до **трёх отличающихся по раскрою схем для
каждой выбранной исходной ширины**, отсортированные по экономике и допуску
массы заказа. Результаты доступны для выбора в окне расчёта закупки.

**Ограничение:** поиск комбинированных схем ограничен размером задачи,
числом типоразмеров и количеством кандидатов. Он выбирает минимум среди
найденных допустимых схем, но не доказывает абсолютный глобальный оптимум
для всех возможных комбинаций или производственных переналадок.
Для больших заказов дополнительно сверяйте результат с технологом.
