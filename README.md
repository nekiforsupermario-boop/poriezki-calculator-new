# Порезки металла

Статическое веб-приложение без сервера: достаточно открыть `index.html` в браузере или разместить содержимое этой папки на GitHub Pages / Cloudflare Pages.

## Что считает текущая версия

- номенклатуру: лента, лист или карточка;
- номенклатуру «Рулон / перемотка» без продольного раскроя;
- для любой карточки проверку обоих направлений: ширина×длина и длина×ширина;
- смешанные схемы полос в одном рулоне, например 1×400 + 2×500 мм;
- ввод количества в тоннах или метрах для ленты/рулона и в тоннах или штуках для листа/карточки;
- перевод выбранного количества в тонны для единого результата в руб/т с НДС;
- плёнку с одной или двух сторон; двухсторонняя плёнка доступна до толщины 2,0 мм;
- при двухсторонней плёнке добавляется вторая перемотка на шлифовке и двойная стоимость плёнки;
- три автоматически подобранные ширины рулона для ленты/карточки;
- автоматический выбор тарифа полного, частичного или открытого рулона;
- ограничения по количеству полос и минимальному откройнику 7 мм;
- ручную ширину рулона;
- металл отдельно от переработки;
- отдельный ввод прайса готового изделия;
- расчёт стоимости откройника от себестоимости материала;
- переработку одной строкой и расшифровкой: порезка + плёнка + шлифовка;
- последовательность операций: для шлифованной продукции сначала шлифовка, затем резка; для карточки — шлифовка (если выбрана), продольная резка в ленту, затем поперечная резка;
- для второй операции автоматически применяется открытый рулон до конца;
- шлифовку рулона по толщине и шлифовку листа по отдельному тарифу;
- минимальные объёмы прайсов: 3 т для продольной резки и шлифовки рулона, 2 т для поперечной резки, 1 т для шлифовки листа;
- доплаты за особые условия, поддон и скидку за дальнейшую переработку;
- лист без расчёта откройника — один вариант по ширине листа.

Текущие условия прайса находятся в объекте `PRICE` файла `app.js`. Цены включают НДС и основаны на присланных прайсах CAMU, LDM/ERIS и ROTOR от 01.03.2026. Все значения сохраняются только в браузере пользователя.

## Бесплатная публикация

### GitHub Pages

1. Создайте новый публичный репозиторий на GitHub.
2. Загрузите в него `index.html`, `styles.css`, `app.js` и `README.md`.
3. Откройте **Settings → Pages**, выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`.
4. Через несколько минут GitHub покажет публичный адрес вида `https://имя.github.io/имя-репозитория/`.

### Cloudflare Pages

1. Создайте проект в Cloudflare Pages и подключите GitHub-репозиторий.
2. Для статического проекта оставьте команду сборки пустой.
3. В качестве папки вывода укажите `/` (корень проекта) и нажмите Deploy.

После публикации ссылку можно открывать на телефоне, планшете и компьютере в любом современном браузере.

## Закрытый доступ без загрузки в интернет

Если коммерческую программу нельзя размещать в интернете, используйте `start-private.ps1` на рабочем компьютере. Скрипт запускает локальный веб-сервер, а файлы остаются только на этом компьютере.

1. Запустите `start-private.ps1`.
2. На этом компьютере откройте `http://localhost:8000/`.
3. На другом устройстве в той же Wi-Fi сети откройте `http://IP-КОМПЬЮТЕРА:8000/`.

IP компьютера можно посмотреть командой `ipconfig` в Windows. Для доступа из другой сети нужен закрытый VPN до офиса или домашней сети; без сервера или VPN ссылку «из любого места» сделать невозможно, потому что приложение должно где-то выполняться.

Другой вариант — держать программу на рабочем компьютере и подключаться к нему через Tailscale/ZeroTier. В этом случае файлы не публикуются, а доступ получают только авторизованные устройства в закрытой виртуальной сети. У бесплатного Personal-плана Tailscale есть ограничение на некоммерческое использование, поэтому для коммерческой работы нужно проверить условия тарифа; ZeroTier также имеет бесплатный базовый вариант для небольших сетей.
